# 天策推文卡片生成器

把 `@Leobai825` 的公开 X 归档做成可搜索、可预览、可下载的推文图片工具。

## 两种模式

1. **历史原推**：正文、日期、点赞、转发来自 2026-07-14 的公开归档。归档没有浏览量和评论数，因此这两项显示为 `—`。
2. **编辑文案**：头像、名字和用户名固定为天策；矩阵同学可以编辑正文，也可以选择天策历史主题作为参考。

评论和浏览量会在每次下载时自动随机生成：评论 70–160，浏览 5–100 万。历史原推的点赞和转发保留真实值，编辑文案模式的互动数据用于模拟排版。所有图片都会保留清楚的真实性标识，不能伪装成真实社交成绩。

## 本地运行

```bash
npm install
node scripts/export-public-tweets.mjs
npm run dev
```

## 数据边界

- 只读取公开推文、点赞数和转发数。
- 不读取私信、联系人、登录信息和其他非公开账号数据。
- 不把别人的原文换成天策署名。
